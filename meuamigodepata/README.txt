# Adote Petz — projeto separado

## Estrutura

- index.html — página principal de adoção
- ongatual.html — cópia da sua página original já separada
- institucional.html — página institucional inicial
- ongs.html — página de ONGs/Protetores inicial
- faq.html — página de FAQ inicial
- parceiro.html — página de parceiro/doação inicial
- css/style.css — todo o CSS que estava dentro do HTML original
- js/script.js — todo o JavaScript que estava dentro do HTML original

## Como abrir

Abra `index.html` no navegador.

O conteúdo original de filtros, cards, cálculo de idade e modais foi mantido no `index.html`/`ongatual.html`; apenas CSS e JavaScript foram retirados para arquivos próprios.

## Importante

As páginas extras são apenas uma base inicial. O conteúdo delas pode ser desenvolvido depois sem mexer na lógica dos filtros da página principal.
